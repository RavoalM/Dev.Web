Parte 1: Questões Teóricas

1. O que é JavaScript? Explique sua função no desenvolvimento web.
JavaScript é uma linguagem de programação usada para criar interatividade em páginas da web, permitindo manipulação de elementos HTML, requisições assíncronas e dinamismo no site.

2. Qual a diferença entre os três tipos de variáveis em JavaScript (var, let e const)?
- var: Escopo global ou de função, podendo ser redeclarado.
- let: Escopo de bloco, não pode ser redeclarado no mesmo escopo.
- const: Escopo de bloco e valor constante (não pode ser reatribuído).

3. O que acontece quando usamos o método prompt()? Qual tipo de dado ele retorna?
O método prompt() exibe uma caixa de diálogo para o usuário inserir um valor e retorna esse valor como uma string. Se o usuário clicar em "Cancelar", o retorno será null.

4. Qual a diferença entre alert(), confirm() e prompt()?
- alert(): Exibe uma mensagem simples.
- confirm(): Exibe uma mensagem com opções "OK" e "Cancelar", retornando um booleano.
- prompt(): Solicita entrada do usuário e retorna um valor em string.

5. Explique o que significa concatenar strings e dê um exemplo utilizando + e template literals.
Concatenar strings significa unir duas ou mais strings.
Exemplo:
let saudacao = "Olá";
let nome = "Ravi";
let mensagem = saudacao + ", " + nome + "!";
console.log(mensagem);
Exemplo com template literals:
let saudacao = "Olá";
let nome = "Ravi";
let mensagem = `${saudacao}, ${nome}!`;
console.log(mensagem);

6. Como podemos converter uma string para número em JavaScript? Dê um exemplo prático.
Para converter uma string para número em JavaScript, você pode usar o método Number() ou parseFloat() para números com casas decimais e parseInt() para números inteiros.
Exemplo:
let numeroString = "10.5";
let numero = Number(numeroString);
console.log(numero);

7. Qual a importância do toFixed(n) quando lidamos com operações matemáticas?
pois ele permite controlar o número de casas decimais exibidas, evitando problemas de precisão que podem ocorrer ao lidar com números decimais.
Exemplo:
let numero = 10 / 3;
console.log(numero.toFixed(2));
