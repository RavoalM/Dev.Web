Parte 1: Questões Teóricas

1. O que é o DOM e qual sua importância no JavaScript?
É a estrutura em árvore da página HTML. O JavaScript usa o DOM para acessar e modificar elementos da página.

2. Qual a diferença entre document.getElementById e document.querySelector?
- getElementById: Busca por ID.
- querySelector: Usa qualquer seletor CSS (ID, classe, tag).

3. O que são eventos em JavaScript? Cite três exemplos.
Eventos são ações que ocorrem no navegador e o JavaScript pode responder a essas ações com funções.
- click: Quando o usuário clica em algo
- mouseover: Quando o mouse passa por cima de um elemento
- keydown: Quando uma tecla é pressionada

4. Explique a diferença entre innerText e innerHTML.
- innerText: Retorna ou altera apenas o texto visível de um elemento, sem considerar tags HTML.
- innerHTML: Retorna ou altera o conteúdo HTML, incluindo as tags.

5. Como podemos alterar o estilo de um elemento HTML via JavaScript?
Você pode acessar a propriedade .style do elemento e mudar qualquer CSS direto por ela.
Exemplo:
document.getElementById("titulo").style.color = "red";
document.querySelector(".box").style.backgroundColor = "black";
